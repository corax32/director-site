# Website fonts

The Alliance No. 1 and Alliance No. 2 WOFF2 assets came from the Palantir website
export supplied for this project on 2026-10-22. They are self-hosted so the site
does not need a font service. This file records provenance; it does not grant
or replace a font licence.

Alliance No. 1 is used for page text and small-screen headings. Alliance No. 2
is used for larger headings and captions. The interactive Lua-menu preview
continues to use its separately bundled Lexend fonts.
